## What this repository provides

- Product descriptions and links to live applications.
- Simplified architecture and workflow diagrams.
- Product journey summaries.
- Dated screenshots of public product pages.

## Publication scope

This is the public documentation showcase for Nouns Technology Group LLC. The application implementation remains in separate private repositories.

This repository does not include private source files, customer records, saved resumes, member conversations, account details, deployment configuration, or credentials.

The architecture is descriptive; it is not an SDK, an API reference, a security certification, or a service-level commitment. Product availability and policies are defined by the live applications.

## Reporting an issue

Use the support or contact options in the relevant live product. Never post passwords, tokens, private documents, payment details, or personal account information in a public GitHub issue.

## Updating this showcase

Update descriptions when product behavior changes, date new screenshots, check relative links, and keep roadmap items separate from available features.
