# Product journeys

[Portfolio](../README.md)

| Product | Start | Main workflow | Outcome |
| --- | --- | --- | --- |
| Nouns | Open the platform | Organize media, select content, create a share | A link or slideshow that can be shared |
| NTM8 | Sign in and set up a profile | Discover people, connect, message, and exchange media | An ongoing personal connection |
| RZM8 | Import a resume and add a target job | Assess, review gaps, confirm experience, edit | A reviewed resume to export or save |
| Chibichi | Browse the current menu | Choose quantities, review cart, checkout | An order that follows payment and fulfillment stages |

## RZM8: user control over the draft

The workflow separates source documents, assessment findings, and the user's reviewed draft. Gap filling should describe confirmed real experience. The person reviews the resulting text before exporting or saving.

## Chibichi: customer and staff views

Customers browse, order, and follow pickup guidance. Staff coordinate availability, payment status, preparation, and completion. The storefront and operational views serve different audiences.

## NTM8 and Nouns: reusable media

Images and videos participate in several workflows: personal galleries, messages, profiles, and shared slideshows. Context determines the visibility and actions available.

For actual access requirements and current availability, use the live product. This document is a portfolio overview rather than an exhaustive user manual.
