# Nouns Technology Group
### Connected products for communication, commerce, and applied AI

Nouns Technology Group LLC builds practical web applications on a shared cloud platform. This public showcase presents the products, user journeys, and architecture behind Nouns, NTM8, RZM8, and Chibichi / Setsuko’s Kitchen.

Built by **Martin Carmain**.

## Architecture and engineering

The platform combines a React / TypeScript frontend with ASP.NET Core APIs, relational data, cloud media storage, and product-specific identity and commerce workflows.

- [Architecture overview and diagrams](docs/architecture.md)
- [Product journeys](docs/product-journeys.md)
- [Public documentation and publication scope](docs/public-documentation.md)

The engineering focus is reusable platform capabilities with clear product boundaries: authentication, localization, media handling, API integration, operational workflows, and AI-assisted experiences.
